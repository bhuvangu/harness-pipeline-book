# Configuring pipeline inputs

A pipeline can declare settings as runtime inputs, and you supply the values
each time it runs — manually on the Run form, from saved input sets, or from
a trigger. Expressions and variables provide values computed during the run.

Use this section to make one pipeline serve many scenarios instead of
maintaining near-identical copies.
