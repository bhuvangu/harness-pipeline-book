# Pipeline concepts

This section explains the model behind Harness pipelines: where resources
live, how they are named, how they are represented and stored, and how the
APIs expose them. The rules described here apply to every entity in the
pipeline offering — pipelines, services, connectors, and the rest all follow
them.

If you read only one section of this guide, read this one — and start with
[How Harness pipelines work](how-it-works.md), which builds the whole
system's mental model deductively, introducing every term before it is
used. The remaining pages treat each part precisely.
