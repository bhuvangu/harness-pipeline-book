# Harness Pipelines API & Entity Reference

This is the reference companion to the [User Guide](../guide/README.md). The
User Guide teaches concepts and tasks; this document gives the precise,
per-entity backing: definitions, identity rules with quoted regular
expressions, ownership and reference edges, YAML examples, API tables for
both API generations, lifecycle states, and known sharp edges.

All content is derived from the frozen corpus (`../corpus/`, frozen
2026-07-16): the filtered OpenAPI specification, the schema digest, the API
path inventory, the documentation set, and the extracted YAML examples.
Each entry cites its sources inline; regular expressions are quoted verbatim
from the schema digest.
